# 餐廳排班小幫手（Claude Skill）

> 把店長在聊天裡貼上的「給班文字」，整理成符合店規的週班表草案，自動標出缺人、崗位缺口與工時風險，並輸出固定版型的 Excel。

**🔗 互動展示頁：**https://claude.ai/artifact/NsbASkLsi9vxWM5BkWm4E7（需先在頁面右上 Share 設為公開）

---

## 解決什麼問題

一間台北義式餐廳，11 名員工（正職、店長、工讀生）。過去排班完全手動：

- 工讀生用 LINE 傳可上班時間，格式不一，容易漏看「不能上」的日期
- 每天要同時滿足：開店人數、11:00 起班人數、午晚餐尖峰人數、七個崗位（司爐、料區、炸區、拍區、控場、吧台、外場）
- 正職採八週變形工時、工讀有週工時上下限與連續工作天數限制，週期計算方式還不一樣
- 排好的週班表要再手動彙總成整月工時表

這個 skill 把上述規則寫成 Claude 可以遵循的工作流程，讓店長只要「貼文字、看結果、做決定」。

## 它做什麼

| 輸入 | 輸出 |
|---|---|
| 聊天貼上的給班文字（不需填表） | 週班表草案（Excel，固定母版） |
| 本週要排哪幾天 | 每日缺口摘要：`午-0`、`晚-1吧台` |
| 「這週確認無誤」 | 獨立確認版週檔 + 累積的整月工時表 |

## 設計重點

1. **候選池 → 刪減**：先把所有可上班時間放進候選池，再依每日需求刪減，避免把「可以上」誤當「必須上」。
2. **硬性條件與彈性條件分開**：開店 1 人、11:00 起班人數、尖峰人數與崗位是班表成立條件；離峰與收店人力只列營運參考，不阻擋班表。
3. **缺口不硬補**：無法滿足時保留缺口並分類為「此草案缺人／已確認無可排人選／資料不足／規則衝突」，不自行突破員工的不可排時間。
4. **兩種週期分開算**：正職以週一至週日統計；工讀以週日至週六統計，跨週連續上班天數不在週日歸零。
5. **確認版不可覆寫**：每週確認後另存獨立檔，校正另存校正版；月表只採最新有效版本。空白（未匯入）與 0（已確認未排班）意義不同。
6. **版型鎖定**：以 Excel 母版為準，禁止 AI 自動調整欄寬、字級或重排工作表，確保店內員工看到的格式永遠一致。

## 迭代紀錄（節錄）

- 早期版本把工讀生的週工時也用週一至週日計算，與店內工讀規則不符 → 改為依身分使用不同週期。
- 曾出現「10:00 開店者被算進 11:00 起班人數」→ 明定只看班次開始時間。
- 週末兩位 11:00 起班者曾只憑「會做」就算達標 → 改為必須實際指派前場組＋內場組崗位。
- 2026-10：正職由四週制改為八週變形工時，週期起點仍待確認，skill 明確要求不自行推定。

> 公開版本中，員工姓名皆以好萊塢演員名代稱，原始檔案路徑已移除。

## 如何使用

1. 將整個資料夾放入 Claude 的 skills 目錄（或在 Claude 設定中上傳此 skill）。
2. 在對話中貼上給班文字，例如 `examples/sample-input.txt`，並說「幫我排 10/26 那週」。
3. 檢查 Claude 產出的 Excel 與缺口摘要，回覆調整或「確認無誤」。

## 限制

- 產出為**預排草案**，不代表實際出勤，也不做薪資核算。
- 勞動法規相關檢查以排班提醒為目的，不構成法律意見；店長核准的店內例外不等於法律豁免。
